# v1.12.0 有限验收基准

## 用户范围决定

2026-10-14，用户在听取积压问题汇总后批准发布 v1.12（"可以发1.12"），本轮工作重点为稳定性、
易用性与降低接入门槛。本次沿用 v1.11.0 的有限范围：按 `cli-fixes` 发布，`full-design-e2e`
延期至 `follow-up`。有限用例全部在冻结候选上重新现场执行，不复用旧候选结果；完整设计 E2E 不补签。
该决定只绑定本版本，不改变其他版本的默认验收要求。

## 候选与输入

产品源码候选为 dev 提交 `fd334d9`（v1.11.0 之后 21 个提交）。连接器运行时自 v1.11.0 起有改动
（无活动文档改报前置条件拒绝、connect_pin 晚到标识采纳、可见文字 bbox 只读动作、silk-align 归属判据、
放置前器件存在性检查、后台安全等待与导入判定），按版本规则递增 minor；CLI/daemon、连接器、npm/lock
与 Skill 正式版本统一为 1.12.0。现场 CLI/daemon 由该候选构建（`v1.11.0-21-gfd334d9-dirty`，dirty
仅为 `make eext` 产生的未提交连接器版本号）；连接器为同一源码构建的开发包，经 IndexedDB 热重载装入
（现场版本 1.11.10），`extension/src` 自候选提交起无改动。正式包只同步版本号、Changelog 与发布材料。

现场使用获准的 ceshi 专用测试工程，其中是 v1.11.0 验收时的 ESP32-S3 最小点灯板（单页原理图、
两层 PCB，10 个器件），来源需求为[最小点灯板](../../../test-case-esp32-blink.md)第一节，文件 SHA256 为
`21bd4682110228de90ee71a8402680eb7668dad5bb7557d44d368d5ff4cd118c`。PCB 语义哈希基准
`226113afd926c4ee…` 与 v1.11.0 验收记录一致。工程身份、原始日志与本地路径不公开。

## 环境与阈值

macOS arm64，Chrome 中的 Web EDA 4.1.71（V4 主线）。本版修复了后台标签页下的导入、重载与轮询等待，
因此全部现场用例在 EDA 窗口最小化（`document.visibilityState` 为 hidden，Chrome 深度节流已生效：
一个 250ms 的裸 setTimeout 实测耗时 66s）的状态下执行，这比前台更严格。
有限用例 M1/F1/F2/E1/L1/N1/R1 的含义以本目录 test-cases.md 为准；它们不是完整设计用例的补签。
阈值：严格门禁 PASS、原生 DRC passed、`pcb check` 0 ERROR、拒绝路径零写入、现场写入均回读核验，
清理后 PCB 语义哈希与基准一致。

完整 B00–B10、完整设计与制造验收不在本次通过范围。
